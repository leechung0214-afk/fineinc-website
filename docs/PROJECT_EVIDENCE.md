## FINE 수행 증빙: 네 건 모두 추가 확인 필요

회사 참여를 단정하는 “실제 수행 경험” 및 “Selected works” 문구도 프로젝트 기록 안내로 변경했다.
확정 실적과 검토 중 기록이 섞이지 않도록 영역 상단과 각 카드에 상태를 명시했다.

2. 담당 범위가 확인되는 과업·발주 자료와 완료·검수·납품 자료 대조. 계약 범위와 실제 수행 범위를 구분.
3. ACC는 개최 예정 상태 유지. 추후 일정이 지났다는 이유만으로 자동 완료 처리하지 않음.
4. 실제 현장 사진은 촬영 행사·일자·저작권·게시 권한 확인 후 추가. 사진만으로 계약 범위 증명 불가.
5. 공개 가능한 증빙 링크 또는 비식별 요약을 카드에 연결하고 확인일 갱신. 연락처·서명·비공개 금액은 공개하지 않음.
6. 검증된 항목만 수행 실적으로 표시. AI 생성 이미지를 현장 사진으로 사용하지 않음.

## 구현

정적 HTML로 일정·장소·설명·공식 출처·수행 증빙 상태를 제공한다.
기존 FINE 로고와 네이비·블루·시안 색상을 유지하며 큰 가상 무대 그래픽을 정보 배너로 대체했다.
프로젝트 영역은 JavaScript가 없어도 보이고, 외부 링크는 새 창 안내와 noopener/noreferrer를 적용했다.
