# 보유 장비 공개 목록

2026-11-06 프로덕션 매니저 운영 데이터베이스의 음향·영상 장비 목록에서 확인한 스냅샷입니다. 삭제되지 않았으며 보유 수량이 0보다 큰 장비만 포함했습니다. 음향 35종, LED 영상 4종입니다.

공개 필드는 분야, 장비명, 분류, 브랜드, 모델, 보유 수량과 LED 패널 규격입니다. 시리얼, 창고 위치, 내부 메모, 판매 이력, 행사 배정, 직원 정보는 가져오거나 게시하지 않습니다. 수량은 당일 대여 가능 수량이 아닌 보유 수량입니다. 등록된 장비명을 그대로 표시하며, 랙·시스템 구성품을 중복 합산하지 않습니다.

`assets/equipment.json`은 확인일 기준 공개용 데이터입니다. 홈페이지에서 운영 데이터베이스에 직접 접속하지 않으며 자동 동기화되지 않습니다. 갱신 시 운영 목록을 다시 확인하고 데이터와 확인일을 수정한 후 아래 명령을 실행합니다.

```bash
python scripts/render-equipment.py
```

생성되는 영역은 index.html의 equipment:start / equipment:end 사이입니다. 음향은 분류별 접기·펼치기, LED는 패널 규격·해상도·보유 수량 카드로 표시합니다. JavaScript를 사용하지 않아도 모든 장비를 확인할 수 있습니다. 새 분류가 생기면 렌더러의 분류 순서를 검토합니다.
